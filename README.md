Coil Checker — это интерфейс к MySQL, который позволяет отметить рулон как «закончен» (с блокировкой повтора и фиксацией времени) или «не закончен» (без фиксации времени, с возможностью повторного использования).

🎯 Для чего это нужно?
Задача	Решение
Не потерять рулоны	Каждый рулон имеет статус
Не обработать дважды	complete блокирует повтор
Знать время завершения	finished_at фиксируется
Гибкость	partial позволяет отметить позже complete
